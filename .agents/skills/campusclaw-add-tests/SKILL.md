# campusclaw-add-tests

输入：change、task、已授权的实现范围和运行环境。

读 AGENTS.md、测试/安全规则、对应 Scenario 和实际接口文档。先确定成败信号是否为独立业务码；基线接口按HTTP契约、返回值与实际副作用判定。用例注明 Requirement/Scenario，按正常、失败、边界组织；失败含跨班与角色越权、非法参数、依赖异常；断言具体值、数据集合与写入结果。

复用已存在的测试运行器与隔离A/B班数据，单元用替身；不为凑用例只匹配源码字符串或重复实现逻辑。范围允许且有意义时，在隔离副本移除一处关键校验，确认用例变红后恢复，证明断言有效。

执行该task规定命令，记录环境、命令、退出码、PASS/FAIL/SKIP和脱敏证据。失败先修复获准范围；缺环境明确记阻塞，不勾task。没有当前任务授权时不启动真实网关、不调用计费模型，不访问生产数据。
