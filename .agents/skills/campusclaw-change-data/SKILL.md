# campusclaw-change-data

输入：change、数据范围、目标环境及允许执行的变更。

读数据/安全/运维规则、对应spec与现有模型，列归属字段、数据字典、敏感分级和全部副本。迁移只增版本，明确兼容期、重跑条件、旧版本可运行性和回滚动作；日期与统计用确定性规则，模型不作最终裁决。

先在隔离测试库执行迁移、重复执行及回滚；删除演练列MySQL/Qdrant/文件/缓存/备份并注入中途失败，验证业务先不可见、清理可重试收敛。不能用清空环境掩盖残留，也不能把软删除等同全部副本已清理。

写入实际执行条件、命令/退出码与脱敏结果，字典和spec随任务同步。真实环境写入/删除不在授权范围时只提供可审阅方案，保留task未完成状态。
