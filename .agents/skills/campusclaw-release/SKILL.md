# campusclaw-release

输入：明确的发布目标、版本/提交、环境、相关change和现有授权边界。

读AGENTS.md、运维/安全/数据规则和已验证发布说明。先核对相关任务及门禁全通过，成员异机复现与人审证据齐全；命令、构建或健康契约缺失则停在缺口，不能假装已具备。按授权范围先把发布和回滚材料做成可审阅结果。

固定源码提交与镜像摘要，核对不含机密；备份→兼容迁移→按已评审策略发布→就绪与主路径核对。失败按预先演练的前版回滚，记录真实耗时和数据处置。标签只指向真实验证的版本；运行骨架通过后才使用v0.0.1-skeleton。

部署、公开发布、数据库修改、密钥轮换或删除必须在当前任务的实际授权范围内；准备材料不等于获得执行许可。用户已经明确授权的动作不重复询问。产出脱敏发布记录和结果；本课仅文档任务不得调用本技能执行外部变更。
