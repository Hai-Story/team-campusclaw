# campusclaw-review-change

输入：change、待审diff或提交范围、验证记录。

按AGENTS.md读取相关规则和完整四件套，先区分文档交付与代码验收。文档阶段检查严格校验、路径链接、候选/已验证事实、任务勾选；代码阶段再查场景执行、越权、副作用、迁移/回滚、提示词评测和门禁。

每条结论引用Requirement/Scenario或规则原文及具体文件；优先报告可观察的错误、范围扩张和证据失真。仅工具连接成功、HTTP200、编译、监听端口都不足以说明端到端完成。

产出：可复核问题、影响、修复建议、验证范围和剩余事项。自动检查与人工批准分别记录，不伪造新会话/异机证据，不通过删除负向用例放行。涉及规则例外应由小组审阅，不默默扩大例外范围。
