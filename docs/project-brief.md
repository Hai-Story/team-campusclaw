# 项目选题与学期范围

## 产品定位

面向中小学教师与学生，在既有平台上增量开发，把知识库与智能体用于备课、命题、学习诊断与课后练习，减少重复整理教学材料的工作，并帮助学生发现和巩固薄弱知识点。

相对通用聊天框，产品将回答绑定本班资料、教学任务、教师审核与可核对的记录；统计与复习规则由确定性程序计算，模型负责生成和解释。

## 现有平台能力

现有平台已实现认证授权与班级隔离、资料上传入库、关键字/向量/混合检索、教学智能体与技能配置、流式会话、MCP工具接入、单题作业、AI初判、教师终评与错题讲解。知识点目录及教师私有备课在此基础上扩展。详见[现有平台概况](platform-overview.md)。

## 六项教学扩展

按知识点基础、智能备课、讲题模拟、知识图谱、智能命题、错题出处、学情诊断、间隔复习、多题作业和集成验收的顺序推进。知识点、备课、讲题、图谱、教师侧命题题库、错题出处和终评诊断已实现，具体验证范围见[教学扩展验证](../reports/learning-expansion.md)；间隔复习、多题作业与集成验收按独立工作包推进。每项执行前明确输入、状态、失败处理、接口兼容和验收场景，本表不替代可执行规约。

| 编号 | 方向 | 规划内容 | 关键依赖与应观察的结果 |
| --- | --- | --- | --- |
| B1 | 智能备课 | 章节、目标、课时与本班讲义输入，生成教案、重点难点、活动、时间分配与资料引用；教师编辑保存 | 讲义检索与教案技能；引用真实可回查，草稿仅创建教师可见 |
| B2 | 智能命题 | 按知识点、题型、难度、题量生成结构化题目、答案与解析，经字段、选项、答案范围和重复校验后存待审核草稿 | 知识点、题库与教师审核；不让未审核生成内容进入正式发布 |
| B3 | 学情诊断 | 从最终批改版本读取得分、满分与确认错因，汇总个人/班级掌握度、频次、趋势与样本数 | 作业与测验记录；程序统计后模型解释，改分后可重新核对 |
| B4 | 知识图谱 | 教师确认模型提取的节点与先修/包含/关联关系，连接资料、题目、错题，先修关系须无环 | 知识点关系与授权；同班节点校验，成环请求拒绝且不写入 |
| B5 | 间隔复习 | 错题/收藏转复习卡，保存等级与到期时间；间隔可配置为 1、3、7、14、30 天，答对升级、答错退首级 | 题目与知识点；服务端按时区与规则计算，不由模型决定日期 |
| B6 | 讲题模拟 | 文本输入思路，保存审题/选方法/推导/检查阶段，结合资料逐步追问，通过 SSE 反馈并归纳改进建议 | 题目、会话与解题引导技能；流式中断与越权有明确处理 |

## 业务主线与 AI 能力

| 业务能力 | 扩展方式 |
| --- | --- |
| 讲义入库与检索 | 复用现有资料管理与混合检索能力，迁移时复核本班隔离、来源与无命中行为 |
| 助手提问与技能 | 继承智能体、SSE、技能与 MCP，按 B1/B2/B6 增加教学场景 |
| 作业提交、批改与错题 | 为B3/B5提供逐份作答与教师终评；错题保留即时反馈，正式成绩与统计只读取教师终评；保留单题并增量兼容多题 |
| 解题引导、作业批改、错题讲解三项技能 | 分别服务讲题、作业与复习路径；需能启停，并按实际职责、执行结果和对应场景逐项验收 |
| 大语言模型、智能体、知识库/RAG、技能、MCP | 通过服务端网关、教学智能体、本班检索、版本化技能、自建鉴权工具服务接入主业务 |
| 异步任务、测试、审计、公网部署 | 在相应后续 change 中列契约与证据；最终演示用页面、接口、日志与真实测试支撑 |

知识点查询与作业统计已接入MCP，复习计划按独立规约推进；工具只能调用已有业务服务，不越过授权层直连存储。图谱使用 MySQL 节点与关系表，Qdrant 继续存向量，维持原技术栈。

## 范围边界

学期主线围绕教师、学生与本班教学；不扩展家长端、多校区运营或交易市场。各项扩展按独立规约实施，先验证运行底座，再交付业务能力。

学生互评及其提交冻结机制暂缓。教师生成流程独立于学生会话，教案、命题草稿与题库属于教师私有业务范围；智能命题先完成内容生产，再接入多题发布与批改。
