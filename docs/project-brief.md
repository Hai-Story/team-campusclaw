# 项目选题与学期范围

## 产品定位

沿用《CampusClaw 小组项目选题说明》（2026-10-14）：面向中小学教师与学生，在既有平台上增量开发，把知识库与智能体用于备课、命题、学习诊断与课后练习，减少重复整理教学材料的工作，并帮助学生发现和巩固薄弱知识点。

相对通用聊天框，产品将回答绑定本班资料、教学任务、教师审核与可核对的记录；统计与复习规则由确定性程序计算，模型负责生成和解释。

## 七项扩展候选

以下是选题说明中的规划，开发顺序与首轮范围待小组确定。每项执行前另建四件套，明确数值、接口、状态、正常/失败/边界场景；本表不替代可执行规约。

| 编号 | 方向 | 选题说明要求 | 关键依赖与应观察的结果 |
| --- | --- | --- | --- |
| B1 | 智能备课 | 章节、目标、课时与本班讲义输入，生成教案、重点难点、活动、时间分配与资料引用；教师编辑保存 | 讲义检索与教案技能；引用真实可回查，保存结果归本班 |
| B2 | 智能命题 | 按知识点、题型、难度、题量生成结构化题目、答案与解析，经字段、选项、答案范围和重复校验后存待审核草稿 | 知识点、题库与教师审核；不让未审核生成内容进入正式发布 |
| B3 | 学情诊断 | 从最终批改版本读取得分、满分与确认错因，汇总个人/班级掌握度、频次、趋势与样本数 | 作业与测验记录；程序统计后模型解释，改分后可重新核对 |
| B4 | 知识图谱 | 教师确认模型提取的节点与先修/包含/关联关系，连接资料、题目、错题，先修关系须无环 | 知识点关系与授权；同班节点校验，成环请求拒绝且不写入 |
| B5 | 间隔复习 | 错题/收藏转复习卡，保存等级与到期时间；间隔可配置为 1、3、7、14、30 天，答对升级、答错退首级 | 题目与知识点；服务端按时区与规则计算，不由模型决定日期 |
| B6 | 讲题模拟 | 文本输入思路，保存审题/选方法/推导/检查阶段，结合资料逐步追问，通过 SSE 反馈并归纳改进建议 | 题目、会话与解题引导技能；流式中断与越权有明确处理 |
| B7 | 学生互评 | 教师定维度、分值、人数和截止；同班分配排除自评并均衡任务；学生评分建议，AI 辅查反馈，教师复核 | 作业与评价流程；人数不足时提示调整，不越班、不自评、不静默覆盖 |

## 课程主路径与五项 AI 能力

| 课程要求 | 小组承接方式 |
| --- | --- |
| 讲义入库与检索 | 继承个人资料与混合检索基线，迁移时复核本班隔离、来源与无命中行为 |
| 助手提问与技能 | 继承智能体、SSE、技能与 MCP，按 B1/B2/B6 增加教学场景 |
| 作业提交、批改与错题 | 作为 B3/B5/B7 的必要业务依赖，后续按课程规约规划发布、截止、提交、批改与教师改分 |
| 解题引导、作业批改、错题讲解三项技能 | 分别服务讲题、作业与复习路径；需能启停并按场景验收，不把个人四个 AI 应用名称等同于三项技能已完成 |
| 大语言模型、智能体、知识库/RAG、技能、MCP | 通过服务端网关、教学智能体、本班检索、版本化技能、自建鉴权工具服务接入主业务 |
| 异步任务、测试、审计、公网部署 | 在相应后续 change 中列契约与证据；最终演示用页面、接口、日志与真实测试支撑 |

MCP 候选工具沿用选题说明的知识点查询、作业统计、复习计划计算；工具只能调用已有业务服务，不越过授权层直连存储。图谱使用 MySQL 节点与关系表，Qdrant 继续存向量，维持原技术栈。

## 本课能力清单

K1：仓库与协作入口；K2：规约四件套；K3：五类必修规则及三类补充规则；K4：可调用流程技能；K5：目录职责与运行骨架设计；K6：真实检查记录、能力场景映射与待办清单。验收位置见 docs/lesson-07/checklist.md。

课件要求本轮能力和任务可判定，没有强制本课选定 B1 到 B7 中的首个业务模块。本课以启动材料为交付；首轮业务迭代：待小组确定。

## 范围边界

学期主线围绕教师、学生与本班教学；不扩展家长端、多校区运营或交易市场。本课按用户说明只进行仓库文档与规划交付；源码迁移、运行验证和发布在后续明确执行阶段开展。
