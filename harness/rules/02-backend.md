# 后端开发规则

适用于 backend/、接口和配置。分层见 docs/architecture.md；旧实现承接见 docs/baseline.md，不把目标结构说成来源已经具备。

| 规则 | 检查方式与不通过条件 |
| --- | --- |
| 边界负责语法/类型/范围校验和鉴权；服务负责状态与业务规则；SQL 只在数据访问层 | 审查依赖与 SQL 位置；服务/handler 新增 SQL 或反向依赖即退回 |
| 既有 API 沿用 /api 与真实 OpenAPI，新增资源路径用小写复数，HTTP 方法对应读/建/改/删 | diff 对照 OpenAPI；改前缀或字段必须有兼容 change，不能照抄课件 /api/v1/ |
| 继承现有成功资源结构及 {error: 文案} 失败结构；接口文档列状态、字段和错误 | 新增第二套业务码封装须先规约，健康探针按本 change 独立结构；未知码不临时编造 |
| 参数非法 400，未登录401，功能级无权403，跨班与不存在404，状态冲突409，超大413，类型错误415，受控依赖故障503 | 每条取真实 OpenAPI 与场景核对；特定旧接口如登录非法输入沿用其文档契约 |
| 新增错误集中记在该 change 与 OpenAPI，用户提示含可执行下一步，不带堆栈 | 对照用例与错误表；无记录返回值先补契约 |
| 每次读写重新校验服务端身份与资源归属 | A/B 班交叉重放；写成功或返回越权数据即失败 |
| 事务只容纳必要数据库读写，不夹带 HTTP/模型/投递/文件上传 | 审查事务范围并注入外部失败；不可回滚副作用存在即失败，跨系统写用事件/补偿并另立规约 |
| 每个写接口先声明幂等与并发策略，唯一性落存储约束 | 相同请求连续与并发执行；重复副作用、覆盖他人更新即失败 |
| 新列表默认 page=1、page_size=20、上限100；超上限按规约截断，排序/筛选字段白名单 | page_size=0/101、非法字段、相同排序值翻页；非法筛选不能退化全量，排序追加唯一 id 兜底 |
| 配置集中从环境读取；必填项缺失/非法非零退出 | 逐个删除必填键及越界端口；不许静默默认值；来源既有默认值的迁移单独评审 |
| 数据迁移只增新版本、可重跑、记回滚；条件语法必须在 MySQL 目标版本验证 | 新旧结构各跑一次，不能把其他数据库的 IF NOT EXISTS 语法当作 MySQL 已支持 |

分页数值为新接口的团队规则；来源接口保持原约定，变更时先写 delta。违反时引用对应 Scenario 退回，不通过扩写实现范围处理。
