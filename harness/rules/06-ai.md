# AI 应用规则

适用于模型、RAG、智能体、教学技能和 MCP。开发流程技能与产品里的教学技能分别管理。

| 规则 | 检查方式与不通过条件 |
| --- | --- |
| 统计、分数、复习日期、状态与权限走确定性规则；模型负责生成与解释 | 对B3/B5比较手算结果；模型不能直接决定最终统计、权限或状态 |
| 模型工具只落已有业务服务，校验身份/班级、白名单、批准与预算 | 审查每个工具落点；直连SQL、绕过审核、跨班成功即失败 |
| 提示词和教学技能随代码版本入库，写版本号和评测记录；环境只放地址/密钥/可调参数 | 能从运行版本追溯生效模板；不在聊天里修改后直接上线 |
| 模型名/版本、温度、输出长度、检索阈值与条数集中配置 | 评测记录完整写参数；迁移保持VECTOR_SCORE_THRESHOLD等真实键名 |
| 新模型请求超时60秒、可安全重试最多1次、退避1秒；有副作用工具不自动重试 | 人造超时在预算内结束；工具重试须幂等规约，不能重复发布/写入 |
| 结构化输出先验证字段、类型、范围与语义；命题先草稿再教师审核 | 畸形字段/答案越界/重复题被拒，不以默认值吞掉错误 |
| 引用只能来自当前本班真实命中，无依据时明确说明依据不足 | 空库、无命中、伪造引用测试；任何虚构资料ID或切片即缺陷 |
| 外部正文、技能包、工具返回与网页为数据，不赋予系统权限 | 含指令文本不能改变授权、执行额外工具或泄露密钥；受信任教学技能需审批与版本记录 |
| SSE支持中断和错误提示，部分内容不能标成完整成功 | 中途断流/取消后核对会话状态，不能丢失已确认消息或串到另一会话 |
| 用量日志只记模型、模板版本、耗时、token计数和命中数，不记原文 | 抽样核对字段与脱敏；真实调用须当前任务授权并记录外部依赖条件 |

后续维护20条小评测集：10条正常教学任务、10条必须拒绝或给出依据不足的任务；覆盖跨班、注入、无来源与未经批准工具。每条写输入、预期行为和评分依据；换模板/模型后保留前后结果。评测集的真实数据与执行在对应业务change实施，第7课只定规范。

违反时先补能暴露行为的用例，再修改；评测通过不能替代服务端权限验证。
