# 数据规则

适用于存储、迁移、统计、删除与备份设计。结构和字段的唯一解释在后续 docs/data-dictionary.md，首次建表时一并建立；本课不空造数据库模型。

| 规则 | 检查方式与不通过条件 |
| --- | --- |
| 新表/字段小写snake_case，业务资源有id、class_id、created_at、updated_at、created_by，时间UTC存储 | 对照数据字典与迁移；无可追溯归属字段的跨资源引用不得合并 |
| 枚举与状态流转在对应spec定义，禁止客户端直接改最终状态 | 终态/并发变更必须明确拒绝与留痕 |
| 迁移版本只增不改，可重跑，写适用版本、向后兼容及回滚 | 在隔离MySQL执行迁移和回滚，不用删除数据解决兼容问题 |
| 成绩与改分保留最终版本来源和追加记录；诊断显示样本数，按最终批改版统计 | 同作业改分前后核对总分/满分，旧版本不能重复计入 |
| 图谱先修关系在同一授权范围，添加前检查成环 | 三节点成环请求不写入，教师未确认候选不进入正式图谱 |
| 复习时间由服务端规则和明确时区计算，1/3/7/14/30天为选题候选配置 | 用固定时钟测等级边界与跨日，重复作答按幂等契约 |

## 敏感分级与留存

| 级别 | 例子 | 范围与处理 |
| --- | --- | --- |
| 公开 | 帮助、协议说明 | 可公开，不含真实学生数据 |
| 内部 | 班级名、资料标题、知识点 | 本班授权可见，日志仅用必要ID |
| 敏感 | 资料正文、答案、成绩、对话内容 | 按具体业务授权，禁止普通日志，导出脱敏 |
| 个人/机密 | 学生身份、提问记录、口令、令牌、密钥 | 最小收集，口令哈希，令牌可吊销，机密不输出 |

教学会话、作答和复习记录规划保留180天（约一学期），到期按授权流程删除；机密凭据按实际有效期吊销。备份默认7天滚动淘汰，恢复时重放删除清单，避免被删数据复活。此为团队目标，业务change落地时明确执行职责。

副本清单逐项登记：MySQL记录、Qdrant向量/切片、上传文件、缓存、备份。删除先记删除意图并使业务不可见，再按副本逐项清理，失败写可重试状态与补偿记录，不能宣称一次跨存储事务可原子删除。备份按保留窗口过期或可验证定向清除处理，不直接擦除全部备份。

单元与接口测试只用合成A/B班数据；生产数据不进开发环境。删除演练在隔离环境故障注入，验证补偿最终收敛，并记录每项副本结果。违反时补字典/副本与回归，涉及真实删除须有对应任务授权。
