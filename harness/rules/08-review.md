# 评审与完成定义

每次工作读取，使用 $campusclaw-review-change 形成可核对结论。

变更完成同时满足：规约场景与越权场景验证通过、匹配阶段的门禁通过、文档同步、证据归档、非作者评审确认；涉及提示词加评测，涉及数据加迁移/恢复证据。本课文档交付完成只表示启动材料已可审阅，不表示运行规约验收通过。

| 事项 | 检查方式 |
| --- | --- |
| 一个change一组能力、实现一次一个task，超400行手写应用改动拆分或说明不可拆原因 | 对照tasks与diff，生成文件单列，不靠文件数掩盖范围 |
| 人审场景、授权、迁移与教学价值；Harness核对规范一致；格式工具处理排版 | PR或评审记录写各自结论，不能把助手自检称为组员批准 |
| 评审人非作者，一个工作日内响应，超期交小组讨论 | 按PR作者/评审与时间核对，不自批 |
| 主干保护、成员权限与教师可读由所有者核对，业务代码只经PR合并 | 验证规则生效和非作者review，不能以“有AGENTS.md”当作平台保护已启用 |
| 提交正文含Change/Verify/Evidence，命令和路径真实 | 抽三条提交反查来源；无运行记录则写待验证，不写PASS |
| 规则、规约、门禁、构建和发布文件变更写明原因，由人确认 | 不因工具执行成功而跳过语义审查；例外须书面、限范围、设失效条件 |
| 所有必需任务通过后归档，由归档更新openspec/specs，运行基线才打skeleton标签 | 任务仍未跑、组员复现未完成则不归档，不写全课验收通过 |

证据放docs/lesson-07或docs/changes/<change>/，至少记录日期、环境、固定提交、命令/步骤、退出码、观察结果与范围。报告与截图不含口令、令牌或学生真实内容；最终页面截图由用户自行完成。

本课bootstrap例外继承根AGENTS.md：初始化无源码文档可直入main，交付后失效；这不是平台保护已配置的证据。后续业务任务必须先让所有者确认平台设置。
