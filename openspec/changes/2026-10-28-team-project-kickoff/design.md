## Context

动因与范围见 proposal.md。小组仓库最初只有 MIT LICENSE；本次不复制应用代码。个人来源固定为 MrKen20/CampusClaw@e5ffbb1677dfad4f5347a4023dc88a5b607c429a，源码核对见 docs/baseline.md。下述运行契约是后续实现的设计，不是本次测试结论。

## Goals / Non-Goals

**Goals:** 固定目录职责、规则与技能入口、配置清单和运行验收行为，让下一次执行只需选择 tasks.md 中的一项。

**Non-Goals:** 本课只创作文档与指令文件；不迁移代码、不安装应用依赖、不启动容器、不跑模型。七项业务扩展的排序留给小组讨论。

## Decisions

### D1. 用独立小组目录承接个人基线

本次在独立 clone 中准备文档。后续迁移采用指定提交的受审查文件清单，保留 LICENSE 与来源；排除 .env、数据卷、uploads、个人 output 和旧测试报告。放弃直接复制整个工作目录，因为它混合了未提交修改与本机状态。

### D2. 分层沿用技术栈，逐模块评审迁移

浏览器 → web/Nginx → Go 路由边界 → 业务服务 → 数据访问接口；模型、向量库与 MCP 在适配层。SQL 仅在数据访问层，新模块按此放置；个人 tutor、mcp 的既有持久化方式在迁移 change 中逐项记录，不声称已经符合目标分层。具体目录见 docs/architecture.md，不为统一目录名做一次性大重构。

### D3. 健康与存活分开

规划 GET /live 为不查依赖的存活探针，GET /health 为聚合就绪探针，公开字段仅含 status、service、version、time、dependencies 和 request_id；依赖对外叫 storage/search/tools，分别映射 MySQL、Qdrant、MCP，值只为 up/down。单依赖超时 2 秒，并发探测，总请求预算 3 秒，不调用模型或嵌入网关。模型配置完整性在启动校验。

个人基线 /health 只返回 status=ok，不查数据库。这里明确规划为新仓库契约的扩展，迁移时须补回归与调用方检查；不把旧接口声称为已通过本课依赖检查。放弃单一存活探针兼任就绪，因为依赖断开时会产生误判。

### D4. 配置外置与兼容边界

.env.example 只留键名；变量含义与必填性见 docs/configuration.md。敏感项与依赖地址缺失立即失败。现有 API 的 /api 路径、HTTP 状态码、成功体与 error 字段沿用个人基线；未来业务码或 /api/v1/ 改造另提 change，不能把课件示例直接覆盖真实契约。运行底座新探针使用独立明确定义的结构。

### D5. 规则与技能入库，代码阶段再验证行为

AGENTS.md 指明开工前读取哪些 harness/rules 文件；五类必修规则各有独立文件，AI、数据、评审也各有一份。Codex 工作流由 openspec init --tools codex 生成，另外补充严格校验、按规约补测试与发布等项目技能。放弃只写 docs/规范汇总而不声明加载入口的做法。此轮只做静态与形式验证；新会话生成代码的实证和组员异机启动保留到代码阶段。

### D6. 本次交付用文档基线，不冒充运行版本

课堂提交默认分支上的文档与目录说明；首次初始化文档允许直接提交主干，作为业务编码前的 bootstrap 例外。此例外仅限本课无源码的启动材料，后续应用改动必须走受保护主干与 PR。运行 tasks 全部验证后才归档及打 v0.0.1-skeleton；当前最多使用文档用途标签，且不自动创建运行标签。

## Risks / Trade-offs

- [七项扩展依赖交错] → docs/project-brief.md 列明作业、题目、知识点与最终批改版本的依赖，不假定先完成某个模块。
- [管理员权限不足] → 邀请成员、配置主干保护由仓库所有者执行，docs/lesson-07/repository-settings.md 给出设置与验证步骤。
- [文档被误认为运行证据] → verification.md 区分已执行的文档检查与待执行的运行检查，tasks 不提前勾选运行条目。
- [旧实现与新规则不一致] → docs/baseline.md 逐项列兼容处置，后续 change 决定迁移，不在本课修改代码。

## Migration Plan

本次仅发布文档；恢复上一文档提交即可回退。后续先确认成员权限与主干保护，再从指定个人提交导入受审查源码，按一个 task 一次实现并验证；运行与恢复演练通过后归档。外部发布需要届时任务授权，不由本次规划自动触发。
