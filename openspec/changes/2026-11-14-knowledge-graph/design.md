## Context

见proposal。knowledge_points及其资料/作业关联已有本班边界；新增关系复用目录，不另建同义节点表。

## Goals / Non-Goals

**Goals:** 可维护正式图谱、私有候选与确定的终评样本。

**Non-Goals:** 不把AI初判计入薄弱统计，不公开未审核生成内容。

## Decisions

- 004迁移新增关系、学科写锁及候选表。对同班同学科图谱写入串行锁，检查先修/包含成环；关联关系按较小ID在前规范化。节点删除级联关系，已有关系的节点改学科409。
- 正式图谱最多500节点、2000关系，超限409；读图返回本学科节点/关系，不创建占位节点。
- 候选保存节点名称/章节/说明与按名称引用的边。生成先用真实本班资料，审核事务再查来源并按当前同学科名称复用节点；新增节点绑定引用资料。候选可版本编辑，不覆盖已有节点说明。
- 模型/检索在事务外，同教师单请求、既有121秒预算；生成键落唯一约束。审核同事务创建节点/关系并标记已审核；任一非法引用、成环或资源变化全笔回滚。
- 薄弱样本只取每学生每作业最新作答且存在当前教师终评，incorrect/reviewed至少一半标为薄弱。学生只统计本人，教师统计本班；即时错题仍取有效对错，与正式统计分开。
- 点选返回本节点与直接先修节点的资料作为复习入口，原资料/作业入口重新鉴权；前端用SVG和可键盘选择的节点展示，不增加图库依赖。

## Risks / Trade-offs

- [并发反向边] → 学科级写锁，后到请求重新检查环。
- [目录或来源被修改] → 审核时重读，失效409；不凭候选旧ID提升权限。

## Migration Plan

只增004结构，保留原知识点与成绩；新旧应用及重跑在隔离库验证。回退保留新增表。
