## Context

已有终评head/history及知识点到单题作业的关联，图谱已从最新作答终评计算样本。

## Goals / Non-Goals

保留单题与旧终评客户端；不回写成绩、不让模型决定掌握度或错因，不创建学生互评资源。

## Decisions

给终评head/history兼容增加可空JSON错因列，列逐个检查以恢复中断DDL；旧行按空数组读取。合法标签concept/calculation/reading/method/careless/other，每类最多一次；正确题标签须空，旧客户端未传时错误题保留已有标签，正确题清空。head和history仍同事务、同版本。

报告在同一只读可重复读事务中读取当前班级学生、知识点关联及最新作答的终评head；不读AI或历史版本。默认最近30个自然日，可选1至180天，Asia/Shanghai日界；以提交日期归趋势，终评改分即时反映。总得分率=sum(score)/sum(max_score)，正确率=correct/samples；知识点按关联样本计算，无样本比例null；多个知识点各自计同一题但总样本只计一次。错误频次只计最终错误题的教师标签，无标签计unclassified。最多10000正式样本，超过返回400提示缩小日期，禁止静默截断。证据分页20/100，字段含作答/作业/学生标识、终评版本、分数和判断，不含参考答案。

教师可筛选当前班级学生；学生不得传student_id并固定本人；他班/不存在学生同形404。报告带确定性fingerprint（范围、当前学生/知识点与样本）；模型只接收汇总、得分率最低20个知识点及最近14天趋势，不发送学生身份和作答正文，结构严格，解释1至2000字；仅允许报告已有数字，不出现得分篡改或虚构出处。无样本不调用模型。前后指纹变化409。生成单次60秒/最多重试1次/121秒总预算、每人并发1，取消不重试。

本地MCP通过既有Manager注册学习服务，教师显式添加、连接发现及按指纹批准后执行。knowledge_points查询与assignment_stats调用已验证业务服务，不直连业务SQL；不接收class_id/身份或学生切换参数。标准JSON-RPC入口沿用服务端会话鉴权，执行同样批准与参数校验；直接RPC工具尝试每人每分钟最多30次（单API进程固定窗口），超限429并提示60秒后重试；JSON-RPC工具错误沿用isError/error，不能仅按HTTP200判成功。会话工具仍受原轮次/次数预算，工具只读、无模型生成与外发。工具返回仅提供有界摘要（知识点每页最多5个、统计最多5个知识点预览），原接口可完整回查。

## Risks / Trade-offs

小样本不能代表整体水平 → 显示样本数及无样本状态。统计解释可能夸大 → 数值只来自报告，教师仍审阅教学建议。报告规模上限显式报错以避免无界响应。

## Migration Plan

MySQL 8兼容增列，重跑不重复；回退旧应用保留列与原终评，隔离演练重启/旧应用及数据库故障恢复，确认旧成绩不变。新错因列无向量/文件副本；回退旧应用在停写窗口执行，保持终评写入暂停，恢复新版后再开放。
