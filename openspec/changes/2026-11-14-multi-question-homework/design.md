## Context
已有私有试卷快照、单题异步初判、独立教师终评与按题统计。多题保持每题独立状态，避免复制第二套批改系统。

## Goals / Non-Goals
保留旧单题接口和记录；完成多题发布、作答、终评与扩展联动。不增加学生互评、自动成绩或修改发布后内容的入口。

## Decisions
- 增量新增published_papers、published_paper_questions、paper_attempts及paper_attempt_submissions。发布保存有序题目/参考答案/解析/知识点/分值/出处快照，每题同时创建一个受父卷管理的grade_assignment；事务创建关联，复用旧任务、发件箱与终评。
- POST /api/paper-drafts/{id}/publish仅创建教师可调用，正文expected_version。每个草稿版本只发布一次，重复返回同一发布；已发布旧版本仍可幂等取回，首次发布版本过期409。发布前复核真实资料与本班同学科知识点；任何失败全部回滚。题库或草稿修改/删除不改变发布快照及成绩。
- 一卷1至50题，每题1至100分，总分≤1000。题型single_choice/multiple_choice/true_false/short_answer；学生响应只有题干、选项、知识点与分值，排除参考答案、解析及可能泄题的出处摘录。教师可读参考与当前出处有效性；发布后来源失效不阻断学生练习。
- GET /api/published-papers按五学科分页；详情及attempts资源均限本班，学生作答仅本人。教师列表默认每学生最新整卷提交，学生查看本人提交历史。单资源越班与不存在同形404。
- POST /api/published-papers/{id}/attempts要求Idempotency-Key（1至64字母数字连字符）及answers数组，包含该卷全部题目assignment_id且各一次。每题answer为字符串：单选有效大写字母；多选逗号分隔有效字母，至少一项且不重复，规范排序；判断true/false转为正确/错误；简答trim后1至4000字。空白、缺题、多题、重复及越界400，整批无写入。仅此接口请求上限1MiB，原接口边界不变。
- 同一事务创建整卷attempt、全部submission/task/outbox及映射；同人同卷同键同规范答案复用原标识，不同答案409。新提交会使每题旧作答失去latest，不沿用旧终评。每题由现有消费者初判，仍只给对错和反馈；教师逐题确认对错、分数与错因。
- 总分从当前整卷各题终评计算；未全部终评时final_score=null，显示已评小计/题数；全部终评后才显示正式总分。诊断、图谱按已终评逐题统计，AI不计正式统计；错题与复习继续取当前有效判断。
- 原单题列表排除受父卷管理的题目；已知题目的读取增量包含paper_id/question_number，父卷题不允许经旧单题提交接口单独重交（409提示整卷提交）。已有独立单题保持原接口、响应字段及历史语义。
- 提供单题/多题切换与题库发布入口，逐题展示作答和初判；批改复用终评组件。已提交记录刷新后从服务端恢复，发布后题面不依赖题库现值。知识点、图谱、诊断及复习的题目跳转能回到父卷，讲题可从具体题目进入。
- 批改数据写入提取为受控事务函数复用；列表/详情批量读取题目和作答，不逐题发起50个数据库或轮询请求。新增记录只在MySQL，不进入共享资料或向量索引。

## Failure / Migration
非法400、未登录401、角色403、资源404、冲突/来源失效409、超大413、类型415、依赖503；批量中任一失败不产生部分提交、孤立任务或分数。只增表，重跑不重复。回退旧应用前在代理暂停作业写操作，验证原单题读取与数据完整，保留多题新增结构；恢复新版本后再开放写入。旧应用缺少父卷约束，因此不声明其可安全承接多题写入。

## Validation
四题型、全量/边界/非法混入、并发幂等与中途失败回滚；题库改题/删除后快照一致；旧单题全链路；逐题判断纠正、总分、跨班及扩展联动；Chrome三尺寸两主题，刷新/错误/重试；100次列表预热5次p95≤500ms。证据写入已有reports/learning-expansion.md。
