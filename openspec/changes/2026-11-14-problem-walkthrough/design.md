## Context

见proposal。单题作业已有本班读取接口，普通会话只供学生使用。新增过程不写入conversations、submissions或成绩。

## Goals / Non-Goals

**Goals:** 确定的阶段推进、本人历史、可取消的生成和刷新恢复。

**Non-Goals:** 不替换普通智能体，不自动评分，不由模型设置阶段。

## Decisions

- 003迁移新增walkthroughs与walkthrough_turns；题面快照、参考答案仅存服务端，响应不含参考答案。本人和班级共同过滤，创建键及回合键落唯一约束。
- 短事务领取130秒租约；模型调用在事务外。成功事务写输出、总结、建议和阶段并递增版本，失败只标记回合，不推进阶段。超时租约读取时恢复为失败，可同键重试。
- SSE先发meta，再调用既有JSON模型适配；校验和持久化后发delta及done，不将未校验JSON流或半截文字展示为成功。取消/断流若早于提交则记录取消；提交后的传输失败通过GET恢复已保存结果。
- 复用tutor内置解题引导提示边界与前端SSEParser；独立walkthrough-v1技能约束结构，不调用工具、不伪造资料引用。每轮保存过程小结与建议，完成阶段汇总整个过程。
- 页面按五学科选择已有作业，支持历史、输入、停止、继续阶段及完成；刷新从服务端恢复。

## Risks / Trade-offs

- [生成中进程退出] → 130秒租约过期恢复，GET显示真实在途状态。
- [模型输出畸形或泄露答案] → 严格校验及复用答案泄露过滤，不保存为成功。
- [重复或并发请求] → 行锁、版本与请求键；后到409。

## Migration Plan

只增表和迁移版本；隔离库验证重跑与旧应用可运行。回退保留新增记录，不删除旧数据。
