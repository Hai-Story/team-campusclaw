## Context

认证为 Authorization Bearer，会话和班级每次查库；浏览器不使用认证 Cookie。runtimehttp 已输出请求日志，observability 已累计模型实际用量；消费者和教师生成另有结构化日志。新增持久层复用这些元数据，不收集请求正文或模型文本。

## Decisions

1. 新增独立 auditlog 存储和上下文记录；迁移只 CREATE 新表和索引，无业务外键级联。API 开始前预留 started 记录，写失败返回503；认证绑定数据库身份后才进入业务。结束更新最终状态，结束落库失败保留 started，不伪造成功。取消后的更新使用独立3秒预算。探针和公开接口说明不依赖审计库。
2. JSON 记录保存 actor_id/class_id、UTC 时间、方法与已注册路由、已校验对象标识、HTTP/执行结果、skill_id、实际 usage 与 duration_ms、request_id。禁止原始查询、正文、口令、令牌、提示词、模型输出及工具参数；工具记录只保留安全状态与数量。字符串白名单、长度上限及 JSON 编码处理换行。HTTP 成功不替代模型完成状态。
3. 异步批改以 task_id+attempt 唯一预留，保存实际用量和结果；预留失败不调用模型、不消耗模型重试次数。旧版本可忽略新增表，回退保留审计数据；迁移重跑不清表。没有历史记录回填或伪造。
4. 列表 GET /api/audit-events，详情 GET /api/audit-events/{id}。教师只查本班；学生403，匿名401，跨班/不存在同形404。page=1/page_size=20，上限100；actor_id 正整数，skill_id 1至80个安全标识字符；from/to RFC3339，缺省最近24小时，最大31天；action、result、request_id 白名单校验，未知参数400。按 id 倒序；首次返回 snapshot_id，后续 before_id 固定快照上界，避免新增审计造成翻页重复；SQL 参数绑定并使用班级/时间及身份、技能索引。
5. 保持 Bearer 登录。有效会话的写请求若 Origin 与当前源不同、Origin 为 null/非法或 Sec-Fetch-Site=cross-site，返回403并留痕；无凭据仍401。无 Origin 的非浏览器请求兼容；不声称配置了认证 Cookie 的 SameSite。部署反代按既有可信入口传递协议，不能由客户端伪造身份。
6. 新教师 audit 状态键：筛选、列表、详情、加载、错误、空态与分页；375/768/1280px不溢出，控件44px；取消陈旧请求，切换账号清空记录。学生不挂载入口，授权仍由后端执行。
7. 原门禁保留；增加隔离的合成泄漏反例作为强制失败证明，正常检查仍扫描完整历史/工作树/前端/日志与依赖。证据记录工作树指纹及真实退出码，不编造新提交。

## Risks / Trade-offs

每个 API 增加审计写入，列表测试以5次预热后100次请求计算p95，超过500ms不通过、超过300ms记录预警。落库依赖失败会拒绝业务；中断留下 started 供排查。审计查询本身也记录，筛选可定位业务事件。匿名请求没有可信班级，不向任意教师公开。数据保留与人工清理按现有运维规约执行，不新增自动删除。

## Validation

先基线 make check，再增量单测/接口/前端渲染与三档布局、重启迁移/旧程序回退、性能与故障注入，最后全量门禁。SEC-08 使用隔离账号与模型真实返回，第四步必须由工具执行层拒绝且业务表不变。其他成员独立复现与实体机器运行保留待完成，不以自动脚本代替。
